主婚與親族
日期、時辰與安床
輸出表報：

大利月依新娘生年地支、以節氣月（正月始於立春）判斷。嫁娶周堂：大月從「夫」順數、小月從「婦」逆數，值第、堂、灶、廚為吉；值翁、姑時，翁姑未設定（不在或迴避）即可用。

參考資料：婚禮流程與禁忌

訂婚程序

  1. 男方備聘禮、六禮或十二禮，依吉時出發
  2. 女方迎接，媒人介紹雙方親友
  3. 奉甜茶，男方回壓茶甌紅包
  4. 新娘坐圓椅、男方戴戒指，再由新娘回戴
  5. 拜女方祖先，女方回禮後宴客
  6. 訂婚宴結束男方不說再見，自行離開

迎娶程序

  1. 男方祭祖後依吉時出發迎娶
  2. 新娘拜別父母，由福壽之人牽出
  3. 出門撐米篩或黑傘遮頭，車行後女方潑水
  4. 新娘丟扇，到男方家摸橘子
  5. 踩瓦片、跨火爐進門
  6. 入廳拜祖先、進洞房，喝交杯酒、吃甜湯圓

歸寧（回娘家）

  • 多在婚後第三天，也有第六、十二天或當天歸寧
  • 帶伴手禮回女方家，由小舅子迎接
  • 宜在天黑前返回男方家

結婚禁忌

  • 婚前四個月內避免參加喪事、探病
  • 喜帖、喜餅不與白事同時送出
  • 屬虎者、孕婦、守孝者不宜送嫁迎娶或進新房
  • 新人在喜宴前不宜碰面（依地方習俗）

新房禁忌

  • 新床安好後到結婚前不宜空床，可請男童「翻舖」
  • 安床後他人不宜坐臥新床
  • 床頭不正對門、鏡子不照床
  • 床不宜壓樑、床下保持淨空

安床要點

  • 依新郎新娘生肖避開沖日、沖時
  • 擇日時看床的坐向，避開當年三煞方
  • 安床日多在婚前三至七天
